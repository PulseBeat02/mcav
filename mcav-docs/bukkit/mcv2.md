# MCV2 on Maps

Besides dithering, `mcav-bukkit` can show video on a wall of maps with MCV2, MCAV's own codec: the server encodes each
frame, sends it as the colours of a few hidden page maps, and a resource pack decodes it on the player's graphics card
at the resolution you choose. Players without the pack see the same wall dithered. Everything about it is on one page,
[MCV2: Video on Vanilla Minecraft Maps](../mcv2.md): the plugin's commands and settings and the Java API are in its
part [Using MCV2](../mcv2.md#part-13-using-mcv2), and the rest explains how the codec works, what it costs, and how it
compares with H.264, VP9 and AV1.
